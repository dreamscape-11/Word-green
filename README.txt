Story Atelier - 기본 버전
1) index.html, manifest.webmanifest, sw.js 파일을 같은 폴더에 둡니다.
2) 웹 호스팅(예: GitHub Pages)에 세 파일을 모두 올립니다.
3) 사이트 주소를 휴대폰 브라우저에서 열어 홈 화면에 추가할 수 있습니다.
4) 처음 사이트를 열고 나면 서비스 워커가 기본 화면을 캐시하여 오프라인 사용을 지원합니다.
5) 데이터는 해당 브라우저의 로컬 저장 공간에 저장됩니다. 브라우저 데이터 삭제 전 반드시 백업하세요.
6) 상단 '백업 내보내기'로 JSON 백업을 만들고, '백업 불러오기'로 복원합니다.
주의: 이 버전은 브라우저별 로컬 저장이며 기기 간 자동 동기화는 지원하지 않습니다.
